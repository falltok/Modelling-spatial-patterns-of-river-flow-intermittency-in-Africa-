# Modelling-spatial-patterns-of-river-flow-intermittency-in-Africa-
Complete access to the scripts used to develop and implement the Random Forest models in the study "Spatial Patterns and Controlling Factors of River Flow Intermittency in Africa"

The complete list of retained gauging stations (coordinates, intermittency classes, and associated environmental variables) and a consolidated file containing all streamflow time series used for model calibration and training can be download at : https://doi.org/10.5281/zenodo.18660605
